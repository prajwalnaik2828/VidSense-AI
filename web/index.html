System Architecture & Diagnostics

Hardware configurations, CPU models, and backend system health metrics.

Engine Specifications

  • Execution Mode: CPU-Only (Zero GPU/CUDA dependencies)
  • YOLO Vision Model: YOLO11n (COCO 80 classes, PyTorch CPU)
  • Multi-Object Tracker: ByteTrack (Persistent Track IDs)
  • Vision Captioning: Google Gemini Vision API
  • Vector Embeddings: sentence-transformers (all-MiniLM-L6-v2)
  • Vector Storage: ChromaDB (HNSW Cosine Similarity)
  • Metadata Database: SQLite WAL mode (tracks, sources, captions)

Quick Performance Tuning

If CPU usage is high on low-powered machines, configure these in vidsense/config.py:

  • YOLO_IMGSZ: 416 → 320 or 256 for faster inference
  • FILE_PROCESS_FPS: 5.0 → 2.0 or 1.0 for faster video uploads
  • LIVE_PROCESS_FPS: 5.0 → 3.0 for reduced live camera load
  • CAPTION_INTERVAL_S: 10 → 30 to minimize external API quota
